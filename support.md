# Support

If you encounter errors, issues, or defects in implementing the Digital River app for BigCommerce, contact the system integrator or partner who installed it.

If you have a defect with the app's functionality, go to [https://support.bigcommerce.com/s/contact](https://support.bigcommerce.com/s/contact) to send an email, start a chat, or call 888-699-8911 opt 1. Include the following information:

* System Integrator or Partner's contact information
* A description of the issue (with a transaction ID if it is available)
* Detailed reproduction steps

For all other questions or inquiries, contact your Digital River representative.
